ESCALA BARNABE

- A escala barnabe foi feita para registrar e admnistrar melhor a saida da rota no caminhão pro estoque
- Criada de maneira justa para não sobrecarregar os colaboradores e manter equilibrio no setor
- Desenvolvido usando as seguintes tecnologias:
  -Python
  -Flask
  -Html
  -css

#Como funciona?
Um gerador em python a partir dos nomes do funcionarios(o input), cria uma tabela em html e css (o output gerando na mesma pasta)simples utilizando
os meses restantes (também é um input porem pelo back end).
